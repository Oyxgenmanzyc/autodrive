五、直接复用现有缓存重新训练 Cost Ranker
--------------------------------------

以下命令不会训练 K67，也不会更新 PCS；只训练独立 Cost Ranker：

bash scripts/pcs/run_3_1_05_6.sh check
bash scripts/pcs/run_3_1_05_6.sh test

test -f "$RANK_FEATURES/complete.json"
test -f "$OOF_ROOT/complete.json"

EPOCHS=20 BATCH_SIZE=32 WORKERS=0 LR=1e-4 \
bash scripts/pcs/run_3_1_05_6.sh train

训练配置：4张 RTX 5880 Ada 物理卡，每卡 batch size 32，全局 batch size 128，20 epochs，FP32，LR=1e-4。最佳 checkpoint 依据 calibration PDM 选择，不按训练 loss 最低选择。成功实验的最佳 epoch 是 14，固定策略 alpha=0.25；重新训练仍应读取新 run 的 result.json，不能硬编码假设每次都是 epoch14。

六、从 PCS candidate cache 重建 Ranker 特征和 OOF
-------------------------------------------------

只有在 features/navtrain 或 oof 不存在时执行：

bash scripts/pcs/run_3_1_05_6.sh prepare

TEACHER_EPOCHS=20 BATCH_SIZE=32 WORKERS=0 \
bash scripts/pcs/run_3_1_05_6.sh oof

EPOCHS=20 BATCH_SIZE=32 WORKERS=0 LR=1e-4 \
bash scripts/pcs/run_3_1_05_6.sh train

OOF 会依次训练三个独立 teacher。每个 teacher 用另外两个日志折训练20轮，再预测未见过的一折，最后生成 oof_scores.npy。三个 teacher 只用于难例挖掘，不参与最终推理。
