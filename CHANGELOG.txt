修改主题：3.3.1 LAST-BEV-Gate 第一版
修改日期：2026-09-21
修改目的：把 LAST-ViT 的通道频域稳定性选择机制适配到 DiffusionDrive 的 8×8 BEV memory，隔离验证对 query aggregation 的影响。
基线：main / 3cf6b7b2750a9bf8ba6d6e4728eafdad44e68e3a；独立于 3.1.x 时序实验。
涉及文件：
  navsim/agents/diffusiondrive/modules/last_token_selector.py

核心改动：
  - 无参数 LASTTokenSelector：FP32 通道 FFT、Gaussian low-pass、signed stability、每通道空间 Top-K、vote 残差软 gate。
  - 修正 Gaussian DC 中心偏移；用 population std 避免单 token NaN；保留原始值梯度。
  - 在 positional embedding 之前选择；decoder memory 和 cross-BEV 独立开关，AMP 下保持原位置编码 dtype。
  - 专用 agent 开启 decoder-only gate，K=16/64、alpha=0.25；通用 config 默认关闭。
  - 可选 trajectory query global 注入及只读 similarity/vote/gate 输出。
  - 无新增 state_dict 键；保留 CNN/GPT/20 anchors/diffusion/loss/100 epoch 优化器调度。
训练配置：
  - 服务器数据根目录：/home/hndx/navsim_workspace/dataset；maps 使用其 maps 子目录。
  - anchor：/home/hndx/navsim_workspace/dataset/kmeans_navsim_traj_20.npy。
  - ResNet-34 权重：/home/hndx/navsim_workspace/dataset/pytorch_model.bin。
  - 物理 GPU 4–7，4 卡 DDP，每卡 batch size 32，全局 batch size 128，学习率 1e-4，100 epochs，16-mixed。
预期影响：检验空间 token 选择是否改善规划信息聚合；不预先断言背景抑制或 PDMS 提升。
测试/验证结果：服务器首次运行 16 项单元测试，15 项通过；零步长 expand view 在 oneMKL FFT 触发 DFTI 配置错误。已在 FFT 前显式 contiguous 修复，待服务器重跑确认；真实数据 smoke test、正式训练和 navtest PDMS 尚未运行。
  单元测试包含冻结 main V2 class 的路由回归，backbone/heads 使用替身；不等价于全模型或真实 checkpoint 验证。
与论文撰写的关系：作为 3.3.1 B2/C1 最小迁移及 B0/B1/B3 对照基础。其余 backbone/causal mask/语义命中率分析不属于本版完成范围。
