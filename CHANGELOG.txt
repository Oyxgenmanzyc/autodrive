修改主题：3.1.05_2：原 PCS hard negatives 的三因子风险否决器（TRV）
修改日期：2026-09-09

修改目的：
保留原 PCS 89.0756 的候选排序收益，仅对原 PCS 实际选择的 candidate 与 base
训练 NC、DAC、TTC 相对风险，减少高置信新增零分；无正收益则作废本实验。

核心改动：
- 冻结原 PCS epoch5 作为 proposer，不重新学习候选排序。
- 从现有 K67 cache 生成可续存的小型 PCS/base 决策对 cache，不重跑生成器或 PDM。
- 相对标签定义为 clamp(base 指标 - candidate 指标, 0, 1)，保留 NC 软退化。
- 三个独立风险头使用 candidate/base/residual 特征及 PCS/原 selector 预测信息。
- focal BCE 对相对退化、新增零分和 PCS 输给 base 的 hard negatives 提高权重。
- 每个 epoch 在独立 val 上搜索三项 OR 否决阈值；搜索包含完全不否决的原 PCS。
- 完整验证同次输出 TRV、原 PCS 和 base，直接统计否决收益及新增零分。

正式结果：

修改主题：3.1.02 原版 DiffusionDrive + Adaptive Multimodal Anchor
修改日期：2026-08-22

修改目的：
在原版 DiffusionDrive 上单独验证自适应多模态 anchor，不引入 3.1.01 的 temporal-pair 训练、GT-protected 梯度投影、temporal energy/ranking loss 或跨帧推理状态，保证 anchor 消融实验变量独立。

涉及文件：
navsim/agents/diffusiondrive/anchors/
navsim/agents/diffusiondrive/modules/multimodal_loss.py
navsim/agents/diffusiondrive/transfuser_agent.py
navsim/agents/diffusiondrive/transfuser_model_v2.py
scripts/anchors/
docs/adaptive_anchor_bank.md
tests/test_adaptive_anchor_bank.py
tests/test_diffusiondrive_variable_anchor.py

核心改动：
1. 从 navtrain GT 提取 `[N, 8, 2]` ego-local 轨迹，离线构建 adaptive anchor bank。
2. 通过 base split、root-conditioned tangent-normal residual codebook、support mask 和 ADE 去重生成多模态 anchor。
3. TrajectoryHead 从 anchor 文件 shape 自动推导候选数量 K，不再固定为 20。
4. decoder、分类分支、回归分支、训练 loss 和推理 gather 均沿用原版 DiffusionDrive，并支持动态 K。
5. 加载旧 checkpoint 时过滤其中的 `plan_anchor`，避免 20-anchor checkpoint 覆盖当前 adaptive bank；其余模型参数保持兼容加载。
6. 对 anchor 文件执行 shape、非空和有限值校验。
7. 未包含 temporal-pair dataset、TemporalPairAgentLightningModule、上一帧轨迹缓存、temporal noise、temporal rescoring、energy ranking 或 GT-protected gradient。

预期影响：
仅改变 DiffusionDrive 的离散轨迹候选集合及候选数量，使长尾轨迹和局部运动模式获得更好的 anchor 覆盖。计算量和显存预计近似随 K 线性增加。

测试/验证结果：
本地不运行训练或完整 smoke test；待服务器执行 anchor 单元测试、variable-K 单元测试和 4 卡 fast-dev-run。

与论文撰写的关系：
该版本作为“原版 DiffusionDrive + Adaptive Multimodal Anchor”的独立消融实验，与 3.1.01 时序优化实验分离，可用于直接比较固定 20-anchor 与 adaptive variable-K anchor 的覆盖率、训练稳定性及 NAVSIM 指标。
