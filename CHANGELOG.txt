修改主题：4.2 版 train-isolated minimal scene-change gated time-aligned temporal compatibility 噪声调制
修改日期：2026-05-31

修改目的：
在第四版 scene-change gate 指标明显下降、且训练日志出现 BEV semantic loss NaN 后，保守收缩场景突变门控并显式隔离训练路径。该版本仍基于第二版 time-aligned temporal compatibility，但移除 LiDAR front-sector 点数、front distance 和 approximate TTC 对 history_weight 的影响，只保留 route command 变化与 ego 动态突变，并在模型 forward 中确保训练期忽略 previous_trajectory/history_weight。

涉及文件：
navsim/agents/diffusiondrive/transfuser_agent.py
navsim/agents/diffusiondrive/transfuser_model_v2.py
tests/test_diffusiondrive_temporal_compat.py
tests/test_diffusiondrive_scene_change_gate.py

核心改动：
1. 在 TransfuserAgent 中缓存上一轮 compute_trajectory() 输出的预测轨迹。
2. 下一轮推理时，将上一轮预测轨迹变换到当前 ego 坐标系。
3. 根据 trajectory_sampling.interval_length 推导时间偏移，默认连续帧间隔 0.5s 时使用 shift_steps=1。
4. temporal reference 只保留真实重叠段 previous_xy_in_current[1:]，不再外推末端点补齐到 8 个点。
5. TrajectoryHead._temporal_noise_scale() 支持 7 点或更短的 aligned previous trajectory，并将 plan_anchor 裁剪到相同 overlap 长度。
6. temporal compatibility cost 改为逐时间点计算 position、delta、speed、heading 四项误差，默认权重为 0.35、0.35、0.15、0.15。
7. 新增上一帧 scene summary 缓存，仅记录 route command、ego speed 和 ego longitudinal acceleration。
8. scene-change score 只覆盖 route command 变化、ego 速度快速下降和当前 ego 急减速。
9. 移除第四版中的 LiDAR front-sector point count、front min distance 和 approximate TTC gate，避免 raw LiDAR 最近点或点数波动误判场景突变。
10. history_weight=clip(exp(-change_score), 0.70, 1.0)，并作为可选 scalar 传入 V2TransfuserModel 和 TrajectoryHead。
11. 第二版 temporal compatibility cost 不变，只在噪声映射前使用 centered_cost=centered_cost*history_weight。
12. history_weight=1 时等价第二版；history_weight 越小，noise scale 越接近 1.0。
13. 不新增第 21 个 anchor，不删除或屏蔽任何低兼容 anchor，不修改训练路径、decoder mode 数、loss 或分类头。
14. 暂不实现安全可行性门控，后续交互式安全评定版本再处理。
15. 增加 scene-change gate 轻量单元测试，覆盖 history_weight 行为、route command 变化、dead zone 和 0.70 下限。
16. 增加 scene_change_dead_zone=0.8；当 change_score 小于该阈值时 history_weight 直接保持 1.0，小变化不触发历史调制衰减。
17. 在 V2TransfuserModel.forward() 中增加训练期保护：self.training=True 时强制 previous_trajectory=None、history_weight=None，确保 temporal inference gate 不进入训练图。

预期影响：
连续帧推理时，平稳场景下保持第二版的 time-aligned temporal compatibility 调制；只有 route command 变化或明显 ego 动态突变时才保守削弱历史轨迹引导。相比第四版，该版本应显著减少 scene-change gate 的误触发；训练时行为应与第二版保持一致，避免 temporal gate 与 BEV semantic loss NaN 混在同一训练图中。
